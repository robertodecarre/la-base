# Joints: range of motion, functional values, couplings

**ROM** = the maximum a healthy adult reaches (AAOS normal values; vary with age, sex, build). A pose near
a ROM limit reads as strained — natural poses live in the **functional / relaxed** range. When a pose needs
a large rotation, distribute it across neighbouring joints: that is what the body does, and skinning
deforms badly when one bone takes ~25°+ that anatomy would share.

## Upper limb

| Joint | Motion | ROM (°) | Relaxed / functional notes |
|---|---|---|---|
| Shoulder (glenohumeral + scapula) | Flexion / extension | 180 / 60 | Beyond ~30° elevation the scapula contributes (≈ 2:1 scapulohumeral rhythm): raise the clavicle/scapula too, not only the humerus |
| | Abduction | 180 | Relaxed at the side ≈ 0–15°; typing 10–15° |
| | External / internal rotation | 90 / 70 | Relaxed arm: slight internal rotation |
| Elbow | Flexion | 0–150 | Typing/desk work 90–103°; hanging arm 5–15° flexed, never locked straight |
| | Carrying angle (valgus when extended) | — | Men 5–10°, women 10–15°; >15° cubitus valgus, <5° varus |
| Forearm (radio-ulnar) | Pronation / supination | 80 / 80 | Hanging arm: neutral (palms toward the thighs). Typing: near full pronation but not quite (palm ~10–15° pinky-side down) |
| Wrist | Flexion / extension | 80 / 70 | Neutral for work; relaxed hand ≈ 10–20° extension |
| | Ulnar / radial deviation | 30 / 20 | Slight ulnar deviation (~5–15°) lines fingers up with work in front of the body |

**Twist rule:** forearm twist lives in the forearm (radius rotates around the ulna), not at the wrist.
Spread a hand roll ≈ 50/50 between forearm and hand bones to avoid "candy-wrapper" wrists.

## Fingers and thumb

| Joint | Motion | ROM (°) | Notes |
|---|---|---|---|
| Finger MCP (knuckle) | Flexion | 90 | Hyperextension 0–45 (varies) |
| | Abduction / adduction (spread) | ≈ 25 total | Keep small in functional poses (index ≤ ~5°); larger spread bulges the knuckle |
| Finger PIP | Flexion | 100–110 | Flexes most in grips and typing |
| Finger DIP | Flexion | 80–90 | Coupled to the PIP (shared tendons): DIP ≈ 0.5–0.7 × PIP in natural curls |
| Thumb CMC (base, trapeziometacarpal) | Flexion / extension | 50–80 range | Also abduction/adduction 40–80 and 10–15 axial rotation (opposition). Opposition is judged functionally (thumb tip to little-finger base) |
| Thumb MCP | Flexion | ≈ 50 | Large individual variation |
| Thumb IP | Flexion | ≈ 80 | |

Total active motion of a finger (MCP+PIP+DIP) ≈ 260–280°.

Functional **typing** angles (keyboard kinematics studies — Sommerich 1996, Nelson 2000, Dennerlein):
MCP 15–37° (decreasing index → pinky), PIP 35–45°, DIP 14–28°.

Sources: AAOS normal ROM values (e.g. physio-pedia "Range of Motion Normative Values", goniometer.io AAOS

studies: men ≈ 5–11°, women ≈ 10–15°); cervical ROM (PMC reviews of cervical biomechanics).
